# واجهة موقع إخباري (RTL)

مشروع واجهة أمامية ثابتة (HTML/CSS/JS) لصفحة أخبار عربية بتصميم حديث ودعم كامل للاتجاه من اليمين إلى اليسار.

## التشغيل
- افتح الملف `index.html` مباشرة في المتصفح.
- أو شغّل خادماً محلياً بسيطاً:
  - Python: `python3 -m http.server 8080` ثم زر `http://localhost:8080`.

## المجلدات والملفات
- `index.html`: البنية الأساسية للصفحة.
- `styles.css`: الأنماط والتجاوب.
- `script.js`: السلوكيات (قائمة الجوال، البحث، التبويبات، السلايدر، الاشتراك).

## ملاحظات
- الصور مستخدمة من خدمات عامة للتجربة (`picsum.photos`).
- يمكنك تعديل الأقسام والعناوين بما يلائم المحتوى الفعلي.
- الخط المستخدم: Cairo من Google Fonts.
